# 🌤️ SkyWorld

تطبيق طقس لنظام Android يعرض حالة الجو بدقة، ويربطها بالأنشطة اليومية للمستخدم (المشي، الركض، قيادة السيارة، والدراجة).

---

## 📌 عن المشروع

* **نوع المشروع:** مشروع شخصي
* **تاريخ التطوير:** 12/06/2026 – حتى الآن
* **الهدف:** تقديم تجربة تفاعلية لمتابعة الطقس وتأثيره على الأنشطة اليومية.

---

## 🚀 التقنيات المستخدمة

* **اللغة والبيئة:** Java | Android Studio
* **أدوات التطوير:** الاستعانة بـ Claude في البرمجة والتصميم
* **واجهة البرمجة (APIs):** WeatherAPI & Nominatim (للبحث وتحديد المواقع)
* **التصميم:** واجهات متحركة مخصصة ومؤشرات نشاط تفاعلية.
